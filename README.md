# Ejercicios de Refuerzo Python

Aquí están todos los ejercicios de las sesiones. Cada archivo tiene el enunciado
escrito como comentarios `#` — léelo completo antes de escribir código.

---

## Cómo empezar cada ejercicio

1. Abre el archivo del ejercicio que te indique el tutor
2. Lee todos los comentarios `#` del archivo
3. Escribe tu código al final del archivo
4. Ejecútalo con el botón **▶** arriba a la derecha

---

## Módulos

| Carpeta | Tema | Ejercicios |
|---------|------|------------|
| `01_funciones/` | Funciones: crear, parámetros, return | 01 al 04 |
| `02_bucles_for/` | Bucle `for`, `while`, acumuladores | 01 al 06 |
| `03_librerias/` | Librerías `math`, `random`, `datetime` | 01 al 04 |
| `04_diccionarios/` | Diccionarios: crear, acceder, iterar | 01 al 04 |
| `05_sistema_menu/` | Listas de diccionarios, menús, CRUD | 01 al 09 |

---

## Cómo ejecutar un archivo

- **Opción 1:** Botón **▶** (Run Python File) arriba a la derecha en VS Code
- **Opción 2:** Clic derecho en el archivo → "Run Python File in Terminal"

---

## Si algo no funciona

- Revisa que Python esté instalado: abre la terminal y escribe `python --version`
- Revisa que la extensión de Python esté instalada en VS Code
- Pregúntale al tutor
