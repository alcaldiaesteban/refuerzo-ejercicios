# Refuerzo Python — Primer Semestre

Bienvenido. Aquí están los ejercicios de práctica para las sesiones de refuerzo.

## Cómo trabajar

1. Abre VS Code en esta carpeta.
2. Instala la extensión de Python si VS Code te lo sugiere.
3. Abre el archivo del ejercicio que te indique el tutor.
4. Lee el enunciado (está escrito como comentarios `#` al inicio).
5. Escribe tu código debajo de la línea `# ESCRIBE TU CÓDIGO ABAJO`.
6. Ejecuta con el botón **▶ Run** arriba a la derecha.

## Módulos

| Carpeta | Tema |
|---------|------|
| `01_funciones/` | Definir y usar funciones |
| `02_bucles_for/` | Bucle `for` y `range()` |
| `03_librerias/` | Librerías `math`, `random`, `datetime` |

## Cómo ejecutar un archivo

- **Opción 1:** Botón ▶ (Run Python File) arriba a la derecha en VS Code.
- **Opción 2:** Click derecho en el archivo → "Run Python File in Terminal".
- **Opción 3:** En la terminal de VS Code escribe `python nombre_archivo.py`.

## Si algo no funciona

- Revisa que Python esté instalado: abre la terminal y escribe `python --version`.
- Revisa que la extensión de Python esté activa en VS Code.
- Pregúntale al tutor.
